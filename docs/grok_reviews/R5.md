# Grok R5 (graphics presets): appraisal

Delivered 2026-09-26. **The paste ends at the heading of the first-run rule**, so that part is missing. Appraised by Claude against the code; Grok's text isn't kept.

**Grade: fair.**
- A tidy table.
- But it sets the reference machine below the game's own defaults, puts SSAO back on in HIGH (the golf-ball look), and assumed a field of view without saying so.
- One mistake was Claude's: the task's facts described fine detail wrongly.

## Claims checked against the code

| Grok said | True? | What the code says |
|---|---|---|
| Fine detail 4 "doubles ground triangles close by" (from the task's facts) | Claude's error | Level 4 is fine detail **everywhere** (`g_fineDetail = 4`, D49, `GROUND_FINE_ALL`), not only close by. The task's facts were wrong; Grok built on them. |
| Field of view 70° in every preset | Unlabelled assumption | The default is 45° vertical (`g_fov`, settings.cpp). Presets shouldn't touch field of view: it's comfort, not performance. |
| MEDIUM (the reference machine) uses fine detail 3, below the default | Wrong target | The defaults were chosen for the reference machine and measured there (world 2–3 ms at 1080p). MEDIUM should *be* the defaults. |
| HIGH turns SSAO on | Conflicts | SSAO made the golf-ball look (D61, D63); it stays off in every preset unless the owner says otherwise. |
| LOW and MEDIUM turn vsync off | Against our rule | The rule is no jitter (CLAUDE.md). The default is vsync on with a 60 cap (settings.cpp); tearing on the floor machine is worse than a lost frame. |
| Shadows "steal VRAM" on a 2 GB card | Small | The three shadow maps are 2048² 32-bit: 48 MB in all. Worth counting, not decisive; the per-frame cost matters more on a weak card. |
| Outlines on in MEDIUM and HIGH | Untested | Outlines are off by default and the owner hasn't judged them on facets (see R4). Leave them off in presets until then. |

## What we'd use

| Setting | LOW (floor) | MEDIUM (reference = defaults) | HIGH |
|---|---|---|---|
| Render distance | 2 | 3 | 5 |
| Fine detail | 1 | 4 | 4 |
| Sun shadows | off | on | on |
| SSAO | off | off | off |
| Bloom | off | on | on |
| Outlines | off | off | off |
| Vsync / cap | on / 60 | on / 60 | on / display |
| Field of view | unchanged | unchanged | unchanged |

This is a proposal to measure, not a decision. The floor machine hasn't been measured at all. A first-run choice from video memory (the one read D21 allows) still needs designing.
