# Grok R7 (M2 options): appraisal

Delivered 2026-09-26. Appraised by Claude against the design and code; Grok's text isn't kept.

**Grade: fair.**
- Sensible and well framed around "a reason to stay".
- But it invented a list of props (chests, lamps, signs, seats) and assumed they could reuse a placement path that no longer exists.
- It missed the owner's own building-layer idea (W067), which Option C depends on.

## Claims checked

| Grok said | True? | What we have |
|---|---|---|
| "Designed props": chests, lamps, signs, seats (Option C) | Invented | DESIGN 4.15 lists beams, corbels, shutters, awnings, pipes, gears, vents, hoppers, struts and bevelled blocks, and all of them were removed in M1.9 (D41). No chests, lamps, signs or seats were ever designed. Grok marked only part of this as an assumption. |
| Crafted props "re-use the existing block-placement path" | False today | Placing works for ground cells only. Anything made needs the building layer first (W067, parked): crisp placed pieces that sit on facets. |
| Plants as cards (Option A) | Fits the design | DESIGN 4.14 already describes plants as cards that turn to face the viewer, one quad each. The build was removed with the old shapes but the idea stands. |
| Growth "with no per-plant tick" | Workable | A plant's stage can be a pure function of its age (planted-at time against the day count), so there's nothing to simulate, only a planted-at time to store. |
| Weather (Option D) | See R2 | Covered in more depth by R2's appraisal. |
| "Music softens underground (already possible)" | Partly | The world-sound census already knows "enclosed" and "deep" (the roof probe, SOUND_PALETTE 3.1) and shapes the ambient sounds. Music doesn't respond to it today; that would be new. |
| Sizes in person-weeks | Not meaningful here | We work in single-system steps (FOUNDATIONS 1); sizes are better given as steps. |
