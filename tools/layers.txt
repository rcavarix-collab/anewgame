# Which layer each source file belongs to (docs/FOUNDATIONS.md 2).
# A file may include only files from its own layer or a lower one.
# tools/check_layers.py enforces this; every compiled file must be listed.
#
#   1 base          maths, constants, profiler, jobs
#   2 platform      window, input, timing, file locations, settings, the string table
#   3 world         cells, materials registry, streaming, terrain, edits, collision, save format
#   4 presentation  meshing, textures, rendering, sky, light, audio engine, sound palette
#   5 game          what walkgrid is: menus, HUD, the tick's game logic, sound choices, saving the game
#   6 app           main.cpp only: wires every layer together
#
# The materials registry (blocks.h) sits in the world layer: its structure is
# engine, its rows are data the engine reads, like textures.
